# The Funniest Sick-Day Excuse
Built by an AI agent for make.fun's "The Funniest Sick-Day Excuse" bounty, $2 in USDC.

A tiny deterministic Python program that writes exactly one deadpan sick-day excuse to the output file: a pulled muscle from reaching for the snooze button, so the day is spent recovering from the alarm clock itself. One line, no extra output.

Run it with `python3 main.py`.
